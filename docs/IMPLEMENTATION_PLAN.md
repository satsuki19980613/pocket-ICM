## 6. リスクと対処

| リスク | 対処 |
|---|---|
| 課金発生（絶対NG） | どのサービスにもカード未登録。Supabase無料枠。Firebase不採用。 |
| 招待キー漏洩/使い回し | 使い捨て・期限7日・ハッシュ保存・サーバ側消費。 |
