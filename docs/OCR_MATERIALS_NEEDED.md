## 必要な素材（優先度順）

### ★★★ 最優先: ② 2.44（超ワイド）でオールインが絡む実機スクショ

| 項目 | 内容 |
|---|---|
| **何の画像** | アスペクト比 **約 2.44（横長・例 1320×540 / 1310×536）** で、**誰かがオールインしている**プリフロップ終了フレーム。オールイン席はスタックが 0 表示＋前に大きなベットチップが出ている状態。 |
| **枚数** | 1〜2 枚（オールインが 1 人のものと、可能なら複数人のもの各 1 枚） |
| **何に使う** | ベットエリアの **アスペクト 2.44 専用グリッド**の較正・検証。現状 `BET_OFFSETS`（`extractAnchored.ts`）は全アスペクト共通で、2.44 ではベット読みが弱い。 |
| **無いと今どうなる** | オールイン**無し**の 2.44 は正常（ベット未読でも下流が blindOb で補償）。だが 2.44 で**オールインが絡むとベット額＝オールイン額を読めない**恐れがあり、ポット計算（Phase 4 ①）が保留（`allin-unread-skip`）になる。 |
| **なぜ今できない** | 較正には実物のオールイン 2.44 フレームが必須。存在しないと座標を推定でしか置けず**検証不能**（さつき方針: 一枚一枚 AI 目視で慎重に較正）。 |

**撮影のコツ**: クラブマッチを 2.44 の端末（横長）でプレイし、オールインが発生したプリフロップ局面のリプレイ終了フレームをスクショ。ファイルは `packages/ocr/local-fixtures/` に保存。

### ★★☆ ③ 「別スピード」の正確なブラインドレベル表（任意）

| 項目 | 内容 |
|---|---|
| **何の情報** | クラブマッチの **「通常」以外のスピード**（ゆっくり等）のブラインドレベル一覧のスクショ。SB/BB/アンティが各レベルで並んだ画面。 |
| **何に使う** | 別スピードのアンティを**厳密化**（現状は読み値＋ 0.25×BB 近似）。 |
| **無いと今どうなる** | **保存則ベースなので機能は動く**（480/960/240 も正しく処理済み）。厳密なアンティが欲しい場合のみ有用。**必須ではない**。 |

### ★☆☆ ④ 2.44 の通常局面をあと数枚（任意・堅牢性向上）

| 項目 | 内容 |
|---|---|
| **何の画像** | 2.44 で人数バリエーション（3人 / 4人 / 6人）の通常（オールイン無し）局面。 |
| **何に使う** | 席アンカーグリッド（`seatAnchorGrids.ts` の `GRID_SUPERWIDE_2P44`）の精度を厚く検証。 |
| **無いと今どうなる** | 現状 2 枚で較正済みで正常動作。増えると安心度が上がる程度。**必須ではない**。 |

## 素材が揃ったときの反映手順（次セッションのメモ）

1. 画像を `packages/ocr/local-fixtures/` に保存（JPEG 拡張子が .png のことがある点に注意）。
2. ② の 2.44 オールイン: AI 目視でベットエリア中心のフラクショナル座標を席ごとに較正し、
   アスペクト 2.44 用のベットオフセット/グリッドを追加。`diagAnchor` で読みを確認。
3. ③ の別スピード表: `blindLevels.ts` に別スピードのレベル配列を追加（保存則ベースは維持）。
4. accuracy ハーネス（`npx tsx scripts/accuracy.ts`）＋実ブラウザ本番経路で回帰ゼロを確認。
