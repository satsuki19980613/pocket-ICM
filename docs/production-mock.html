用語

PU Push
まだ誰もチップを入れていない状態から、最初にオールインする側。ツリー上段。
CA Call
PUに対してコールする側。まだ誰もコールしていない状態での受け。
OC Overcall
PUとCAが既に入っている場面でさらに乗る側。2人に囲まれる分ずっと狭くなります。
Range
そのアクションを取るハンドの集合。押し引きの均衡では0か100かで、混ぜる手はありません。
EV
自分のこのハンドで、PUした場合とFOLDした場合の期待pt差。プラスなら押しが得。一番見てほしい数字です。
EQPre / EQPost / EQDiff
ハンド前後の期待ptとその差。レンジ全体の平均で「この場面が有利かどうか」を表します。
ICM Independent Chip Model
チップ量を期待獲得ptに変換するモデル。飛ぶリスクが実際より重く効きます。
Effective stack
実際にやり取りされる最大チップ量。短いほうのスタックで決まります。
