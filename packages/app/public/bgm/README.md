# BGM（Slumbot 対戦画面）

このフォルダに置いた音源が、Training ▸ Slumbot HU の **♪ ボタン**で鳴ります。

## 置き方

**ファイル名は `slumbot.mp3` に固定**してください（プログラムがこの名前で探します）。

```
packages/app/public/bgm/slumbot.mp3
```

置いたら `npm run build --workspace @oshihiki/app` → push でそのまま配信されます。
差し替えるときも、同じ名前で上書きするだけです（利用者の端末には最大 1 時間ほどで届きます。
`public/_headers` の `/bgm/*` で決めています）。

## 音源の条件

| 項目 | 決め | 理由 |
|---|---|---|
| 形式 | MP3 | iOS / Android / PC の全ブラウザが再生できる唯一の共通形式 |
| 長さ | 1〜3 分 | ループ再生するので、長すぎると読み込みが遅い |
| 容量 | **5MB 以内**を推奨 | 毎回ダウンロードするため。128kbps で 3 分ならおよそ 3MB |
| 音量 | 小さめに書き出す | アプリ側でも 35% に絞っているが、音源自体が大きいと耳に痛い |
| 頭と尻 | 無音を入れない | ループの継ぎ目で「間」が空く |

## 注意

- この音源は **PWA の事前キャッシュに入れていません**（インストールが重くなるため）。
  初回の再生だけ通信が要ります。オフラインでは鳴りません。
- iPhone の**消音スイッチが入っていると鳴りません**（ブラウザから制御できない仕様）。
- 権利のある曲は置かないでください。ここに置いたファイルはそのまま公開されます
  （`https://pocket-icm.wsk641.workers.dev/bgm/slumbot.mp3` で誰でも取得できます）。
  フリー音源を使う場合も、ライセンス表記が要るものは設定画面などに出す必要があります。
