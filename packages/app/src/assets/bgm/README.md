# BGM（Slumbot 対戦画面）

このフォルダに **MP3 を置くだけ**で曲が増えます。コードを触る必要はありません
（ビルド時に自動で拾います・`src/slumbot/bgmTracks.ts`）。

```
packages/app/src/assets/bgm/*.mp3
```

置いたら `npm run build --workspace @oshihiki/app` → push で配信されます。

## 曲名は「ファイル名」がそのまま出ます

設定画面（⚙ ▸ ゲーム設定 ▸ BGM）に並ぶ曲名は、ファイル名から作ります。

| ファイル名 | 画面に出る曲名 |
|---|---|
| `neon-drive.mp3` | neon drive |
| `01-夜の高速.mp3` | 夜の高速 |
| `02_glitch_city.mp3` | glitch city |

- 先頭の `01-` `02_` は**並び順の指定**として使われ、曲名からは外れます。
- `-` と `_` は空白になります。
- 並び順はファイル名順です（順番を決めたいときは `01-` `02-` を付けてください）。

## 音源の条件

| 項目 | 決め | 理由 |
|---|---|---|
| 形式 | MP3 | iOS / Android / PC の全ブラウザが再生できる唯一の共通形式 |
| 長さ | 1〜3 分 | ループ再生するので、長すぎると読み込みが遅い |
| 容量 | **1 曲 5MB 以内**を推奨 | 鳴らした曲だけ落ちてくる。128kbps で 3 分ならおよそ 3MB |
| 音量 | 小さめに書き出す | アプリ側でも 35% に絞っているが、音源自体が大きいと耳に痛い |
| 頭と尻 | 無音を入れない | ループの継ぎ目で「間」が空く |

曲数が増えてもアプリのインストールは重くなりません（音源は PWA の事前キャッシュに
入れていないため）。落ちてくるのは**実際に鳴らした曲だけ**です。

## 注意

- 初回の再生だけ通信が要ります。**オフラインでは鳴りません**。
- iPhone の**消音スイッチが入っていると鳴りません**（ブラウザから制御できない仕様）。
- 権利のある曲は置かないでください。ここに置いたファイルは配信物に含まれ、URL を知れば
  誰でも取得できます。フリー音源でもライセンス表記が要るものは、表記を出す必要があります。
- ファイルを差し替えると配信 URL のハッシュも変わるので、古い音源が残ることはありません。
